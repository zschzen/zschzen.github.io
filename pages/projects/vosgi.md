Vosgi is a text-based game engine: the machinery for games where the interface is prose and the mechanics are choices. Ubura is the lexer built into it, which parses game scripts so the engine can bundle them with their assets.

The goal was a streamlined workflow for game scripting and asset management, so authors could focus on story and mechanics while the tooling handled parsing and packaging.

## Features

- **Ubura lexer**: tokenizes game scripts for the engine
- **Bundling**: packages scripts and assets into a distributable game
- **Asset management** built into the authoring workflow
